MaterialX Protobuf Converter - C++ Version

This directory contains the C++ implementation of the MaterialX Protobuf converter, equivalent to the Python version.

Features

  • Convert MaterialX XML documents to Protocol Buffer binary format (.mxpb)
  • Convert Protocol Buffer documents back to MaterialX XML
  • Export to JSON format
  • Generate Mermaid diagrams for visualization
  • Debug inspection tools for protobuf documents

Prerequisites

Required Libraries

  1. MaterialX C++ Library (version 1.39.4 or later)
    • Download from: https://github.com/AcademySoftwareFoundation/MaterialX
    • Build and install following their instructions

  2. Protocol Buffers C++ Library (version 3.0 or later)

    Windows:

    choco install protobuf
    vcpkg install protobuf

    macOS:

    brew install protobuf

    Linux:

    # Ubuntu/Debian
    sudo apt-get install libprotobuf-dev protobuf-compiler
    # Fedora/RHEL
    sudo dnf install protobuf-devel protobuf-compiler
  3. CMake (version 3.14 or later)

Building

Generate Protobuf C++ Code

First, generate the C++ protobuf files from the .proto schema:

# From the project root
cd source
protoc --cpp_out=../cpp materialx.proto

Or use the provided script (from project root):

./generate_stubs.sh

Build the Executable

On Windows:

cd cpp
build.bat

To install:

build.bat install

On macOS/Linux:

cd cpp
chmod +x build.sh
./build.sh

To install:

./build.sh install

Manual CMake Build

If you prefer manual control:

cd cpp
mkdir build
cd build
# Configure
cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr/local
# Build
cmake --build . --config Release
# Install (optional)
cmake --install .

Specifying Library Paths

If CMake cannot find MaterialX or Protobuf, you can specify their locations:

cmake .. \
-DCMAKE_BUILD_TYPE=Release \
-DMaterialX_DIR=/path/to/materialx/lib/cmake/MaterialX \
-DProtobuf_DIR=/path/to/protobuf/lib/cmake/protobuf

Usage

The C++ executable has the same command-line interface as the Python version:

Convert MaterialX to Protobuf

./materialxpb document.mtlx

This creates document.mxpb in the same directory.

Convert Protobuf to MaterialX

./materialxpb document.mxpb

This creates document_from_pb.mtlx in the same directory.

Additional Options

Convert and verify round-trip:

./materialxpb document.mtlx --convert_back

Output JSON representation:

./materialxpb document.mtlx --json

Generate Mermaid diagram:

./materialxpb document.mtlx --write_mermaid

Specify output folder:

./materialxpb document.mtlx --output_folder ./output

Debug inspection (3 levels of detail):

./materialxpb document.mtlx --debug_pb_doc 1 # Simple tree view
./materialxpb document.mtlx --debug_pb_doc 2 # Compact with attributes
./materialxpb document.mtlx --debug_pb_doc 3 # Full detail

Combine options:

./materialxpb document.mtlx --json --write_mermaid --output_folder ./results

Command-Line Options

Option Short Description
--json -j Output JSON representation of the Protobuf document
--convert_back -cb Convert back to MaterialX after Protobuf conversion
--write_mermaid -wm Output Mermaid diagram of the Protobuf document
--output_folder -of Output folder for converted files
--debug_pb_doc -dbg Enable debug output (1=simple, 2=compact, 3=full)
--help -h Show help message

Code Organization

The C++ code is organized into several components:

MaterialXToProtobuf Class

Converts MaterialX documents to Protobuf format:

  • Traverses MaterialX element hierarchy
  • Preserves attributes and structure
  • Sets schema version information

ProtobufToMaterialX Class

Converts Protobuf documents back to MaterialX:

  • Validates schema version compatibility
  • Reconstructs MaterialX element hierarchy
  • Handles attribute restoration

Util Class

Utility functions for working with protobuf documents:

  • fromString() / toString() - Binary serialization
  • toJson() - JSON export
  • debugInspect*() - Various inspection modes
  • generateMermaidDiagram() - Diagram generation

VersionUpgrader Class

Handles schema version migrations:

  • Version comparison utilities
  • Upgrade path definitions (for future versions)

Performance Notes

The C++ version offers:

  • Faster processing of large MaterialX documents
  • Lower memory footprint
  • Native binary execution
  • No Python runtime dependency

Troubleshooting

CMake cannot find MaterialX

Set the MaterialX installation path:

cmake .. -DMaterialX_DIR=/path/to/materialx/lib/cmake/MaterialX

CMake cannot find Protobuf

Set the Protobuf installation path:

cmake .. -DProtobuf_DIR=/path/to/protobuf/lib/cmake/protobuf

Linking errors on Windows

Make sure you're using the same C++ runtime library for all dependencies. Use vcpkg or ensure consistent build settings.

Missing DLLs at runtime (Windows)

Add the MaterialX and Protobuf DLL directories to your PATH:

set PATH=%PATH%;C:\path\to\materialx\bin;C:\path\to\protobuf\bin

Development

To modify the protobuf schema:

  1. Edit ../source/materialx.proto
  2. Regenerate C++ code: protoc --cpp_out=. ../source/materialx.proto
  3. Rebuild: cmake --build build --config Release
